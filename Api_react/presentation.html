✅ การตรวจสอบและป้องกัน

• trim() ตรวจสอบค่าว่าง: แจ้งเตือนสีแดงทันทีเมื่อไม่มีการกรอกคำค้น

• ป้องกัน Submit ซ้ำ: ปิดการทำงานปุ่มค้นหาระหว่างดึงข้อมูล

• Graceful Fallback: มีรูปภาพจำลองเมื่อซีรีส์ไม่มีโปสเตอร์

⭐ ข้อมูลเพิ่มเติมที่แสดง

• คะแนนเรตติ้ง (Rating): เช่น 7.8 / 10 พร้อมดาว

• หมวดหมู่ (Genres): แท็กประเภท เช่น Action, Comedy

• สถานะและปีฉาย: กำลังฉาย / จบแล้ว พร้อมปี ค.ศ.

• Modal เจาะลึก: แสดงเรื่องย่อ ช่องที่ฉาย และลิงก์ทางการ
