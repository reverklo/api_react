## 📋 ข้อมูลภาพรวม (Overview)
- **ชื่อแอป**: Series Finder
- **เทคโนโลยี**: React 18, JSX, TVmaze API, Modern Glassmorphism CSS
- **Data Flow**: `Form (Input) → API (TVmaze) → State (React) → UI (Render)`

## 🗣️ บทพูดนำเสนอแบ่งตามสมาชิก (2-3 นาที)

### 👤 สมาชิกคนที่ 1: แนะนำตัว & แนวคิด/User Journey (ประมาณ 45 วินาที)
> "สวัสดีครับ/ค่ะอาจารย์และเพื่อนๆ วันนี้กลุ่มเราจะมานำเสนอโปรเจกต์ **Series Finder** ซึ่งพัฒนาด้วย **React 18** เชื่อมต่อกับ **TVmaze API** ครับ/ค่ะ
> 
> ในส่วนของ **User Journey** เราออกแบบไว้ 5 ขั้นตอนตามหลัก UX ที่ดี:
> 1. **กรอกคำค้น**: มีช่องค้นหาพร้อมปุ่มแท็กแนะนำคำค้นด่วน (Quick Tags)
> 2. **ค้นหา**: กดปุ่ม Search หรือกด Enter โดยหน้าเว็บไม่โหลดใหม่ (`e.preventDefault()`)
> 3. **รอผล**: มี Skeleton Loading และ Spinner แสดงระหว่างดึงข้อมูล
> 4. **ดูผลลัพธ์**: แสดงการ์ดซีรีส์พร้อมคะแนนเรตติ้ง หมวดหมู่ และมี Modal ดูเรื่องย่อแบบเจาะลึก
> 5. **ค้นใหม่**: มีปุ่มล้างคำค้น (Clear) ให้ผู้ใช้ค้นหาเรื่องใหม่ได้อย่างสะดวกรวดเร็วครับ/ค่ะ"

---

### 👤 สมาชิกคนที่ 2: อธิบาย Form, State และ Data Flow (ประมาณ 45 วินาที)
> "สำหรับส่วนของฟังก์ชันการทำงาน และ **Data Flow**:
> 
> 1. **Form & State**: เราใช้ `useState` ในการควบคุมค่า input (`query`) และผูกกับ `<label>` อย่างถูกต้อง
> 2. **Validation**: ก่อนส่ง request เราใช้ `trim()` ตรวจสอบค่าว่าง หากผู้ใช้กดค้นหาโดยไม่พิมพ์อะไร ระบบจะแสดงข้อความแจ้งเตือนสีแดงทันที
> 3. **API Integration**: เราสร้าง URL ด้วย `URLSearchParams` และดึงข้อมูลด้วย `fetch()` แบบ `async/await` จาก `https://api.tvmaze.com/search/shows?q=...`
> 4. **State Management**: เราจัดการ 4 สถานะหลักอย่างสมบูรณ์ ได้แก่ **Loading**, **Success**, **Empty** (เมื่อไม่พบผลลัพธ์), และ **Error** (หากเน็ตหลุด พร้อมปุ่ม Retry)
> 5. **การป้องกันข้อผิดพลาด**: เราปิดการกดปุ่ม Submit ซ้ำระหว่างกำลังโหลด (`disabled={isLoading}`) และใส่ Fallback รูปภาพเมื่อข้อมูลจาก API ไม่มีรูปภาพครับ/ค่ะ"

---

### 👤 สมาชิกคนที่ 3: สาธิตการทำงานจริง (Demo) (ประมาณ 45 วินาที)
> "ต่อไปจะเป็นการสาธิตการทำงานของแอปพลิเคชัน 2 กรณีตามเกณฑ์ครับ/ค่ะ:
> 
> 📌 **กรณีที่ 1: สาธิตคำค้นว่าง (Empty Search)**
> *(กดปุ่ม 'ค้นหา' โดยไม่ต้องพิมพ์ข้อความ)*
> 👉 จะเห็นว่าหน้าเว็บไม่รีเฟรช และมีกล่องแจ้งเตือนสีแดงเตือนว่า *'กรุณากรอกชื่อซีรีส์ที่ต้องการค้นหา (ห้ามเว้นว่าง)'*
> 
> 📌 **กรณีที่ 2: สาธิตค้นหาซีรีส์จริง (Real Search)**
> *(พิมพ์คำว่า 'Batman' หรือกดแท็ก 'Batman' แล้วกดค้นหา)*
> 👉 จะสังเกตเห็น Skeleton Loading ขึ้นมาขณะรอผล แล้วแปลงเป็น Grid การ์ดซีรีส์ มีเรตติ้ง ⭐ มีประเภทเรื่อง และปีที่ฉาย
> 👉 เมื่อคลิกที่การ์ด จะมี **Modal Popup** แสดงเรื่องย่อ รายละเอียดช่องออกอากาศ และลิงก์ไปยังเว็บทางการ
> 
> กลุ่มของพวกเราขอจบการนำเสนอเพียงเท่านี้ ขอบคุณครับ/ค่ะ!"
